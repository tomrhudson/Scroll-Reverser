# ARCHIVE/

Retired files and superseded versions. Don't delete history — move it here.

## Naming Convention

`original-filename_vN_YYYY-MM-DD.ext` or `original-filename-old_YYYY-MM-DD.ext`

## Structure

Files are stored flat.

## When to Archive

- When a file is replaced by a new version
- When a feature, script, or config is deprecated but may be referenced later
- When restructuring the repo and old files no longer fit the new layout
