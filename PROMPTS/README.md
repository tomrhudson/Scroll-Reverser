# PROMPTS/

Reusable prompt templates for this repo.

## Naming Convention

`purpose-description.md` — lowercase, hyphen-separated.

## How to Use

Each file contains a self-contained prompt with context, the prompt text, and expected behavior. Copy and adapt as needed.

## Versioning

When revising a prompt, update the file directly and note the change date at the top. Move superseded versions to `ARCHIVE/` if the change is significant.
